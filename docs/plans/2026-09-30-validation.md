# SAR 기능 및 성능 재검증

요청: apartment_sar에서 GPU 렌더링과 YOLO를 유지하면서 느린 Fast 모드의 원인을 측정하고 탐색, 탐지, 지도, 위치 표시, 복귀 기능을 검증한다.

## 관측 및 기준
- 시작 시 기존 순수 Python 테스트 15/15 통과.
- YOLO 예외를 성공으로 처리하고 이전 프레임 박스를 새 영상에 재사용한다.
- 현재 위치 추정은 인코더+컴퍼스이며 scan matching/loop closure는 없다.
- 성공 기준은 단순 DONE 도달과 실제 목표 방문을 구분해야 한다.

## 진행 순서
1. 기존 영상/지도/미션 코드 프로파일과 오프라인 E2E로 기준 측정.
2. 재현 테스트를 먼저 추가하고 확인된 좌표/탐지/완료 판정 오류 수정.
3. 동일 동작을 유지하는 영상 처리 최적화. 센서/물리/렌더링 대기와 Python 시간을 분리해 계측.
4. YOLO 장치 및 실패 상태를 명시하고 같은 프레임 결과를 공유. 지도/카메라/위치/진행 상태를 실시간 페이지에 표시하고 지도 데이터를 저장.
5. 실제 Webots 재시작 후 CUDA, PNG/상태 갱신, 경로/목표 방문/복귀를 관측. 성능과 잔여 한계를 보고.

범위: 근거 없는 주행 속도 상향이나 물리 timestep 변경은 하지 않는다. 기존 월드와 사용자 뷰 설정을 보존한다. SLAM이 구현되지 않은 상태를 SLAM 완료로 표시하지 않는다.

검증: 기존 테스트 + 재현 테스트 + 오프라인 복수 지형/동적 장애물 + 실제 GPU 추론 및 Webots 실행 계측. 오프라인 합격이 실제 인식 정확도나 모든 환경 무충돌을 보장하지 않는다.
