# 자율 탐색·목표물 방문·복귀 시스템 — 7분 발표 대본

작성일: 2026-09-30. 보통 속도로 읽고 화면을 짚어가며 설명하면 약 7분입니다. 실제 발표 전 리허설로 시간을 조절하세요. 코드 구현과 단위 테스트 통과를 실제 아파트 임무 완주와 구분하여 설명합니다.

## 0:00~0:45 — 프로젝트 소개

안녕하세요. 이번에 구현한 프로젝트는 Webots의 아파트 환경에서 로봇이 지정된 색상의 목표물을 탐색하고, 목표물을 모두 방문한 뒤 시작 지점으로 돌아오는 자율 탐색 시스템입니다.

로봇이 자율적으로 움직이려면 크게 네 가지 질문에 답할 수 있어야 합니다. 주변에 무엇이 있는지, 자신이 어디에 있는지, 어디로 이동해야 하는지, 그리고 언제 임무를 끝낼 것인지입니다.

저희는 이 문제를 카메라 기반 객체 탐지, LiDAR 기반 지도 작성, 위치 추정, 경로 계획, 그리고 임무 상태 관리로 나누어 구현했습니다. 각 기능을 따로 만드는 것뿐 아니라, 실제 주행 중 서로 연결되어 동작하도록 구성하는 데 중점을 두었습니다.

## 0:45~1:50 — 목표물 탐지와 YOLO

먼저 목표물 탐지입니다.

카메라 영상에서는 HSV 색상 정보를 이용해 지정된 색상의 영역을 찾습니다. HSV는 색상과 밝기를 분리해서 표현하기 때문에, RGB 값을 직접 비교하는 것보다 특정 색상을 기준으로 후보를 추리는 데 적합합니다.

하지만 빨간색이라는 이유만으로 목표물이라고 판단하면 문제가 생깁니다. 아파트에는 빨간 소화기나 가구, 벽의 글자처럼 목표물과 색상이 비슷한 물체도 있기 때문입니다.

그래서 색상뿐 아니라 영역의 크기와 형태, 화면에서의 위치를 함께 확인하도록 했습니다. 여기에 YOLO를 연결해 물체의 종류를 추가로 확인합니다. 현재 구조에서는 색상과 기하 조건으로 후보를 찾고, YOLO가 병과 같은 다른 물체로 판단하면 후보를 제외하는 방식으로 사용합니다.

이렇게 구성한 이유는 기본 YOLO 모델이 시뮬레이션의 단순화된 사과를 항상 정확하게 분류하지는 않기 때문입니다. 실제로 사과를 스포츠 공으로 분류하는 사례도 있어서, 이러한 혼동을 고려한 예외 처리를 추가했습니다.

추론은 CUDA를 통해 GPU에서 수행하며, 기본 실행 주기는 시뮬레이션 시간 기준 약 0.25초입니다. 같은 영상에 대한 결과는 재사용해서 불필요한 중복 추론을 줄였습니다.

## 1:50~2:45 — 지도에 목표물이 표시되는 원리

다음은 지도 작성입니다.

로봇은 LiDAR로 주변 장애물까지의 거리를 측정하고, 이 정보를 작은 격자로 나눈 지도에 누적합니다. 각 칸은 관측에 따라 빈 공간, 장애물, 아직 모르는 공간으로 구분됩니다. 따라서 처음부터 완성된 아파트 지도를 알고 움직이는 구조는 아닙니다.

여기서 로봇이 직접 가보지 않은 위치에도 목표물 표시가 나타날 수 있습니다.

이는 카메라에서 목표물을 본 방향과 화면에 나타난 크기 등을 이용해, 목표물이 있을 것으로 예상되는 좌표를 계산하기 때문입니다. 물체를 보는 것과 그 위치까지 방문하는 것은 서로 다른 사건입니다.

기존에는 이 차이가 화면에서 명확하지 않아, 방문하지 않은 목표물도 이미 찾은 것처럼 보일 수 있었습니다. 이를 개선하기 위해 아직 방문하지 않은 목표물의 추정 위치는 노란색으로, 방문이 완료된 목표물은 빨간색으로 구분했습니다.

또한 목표물이 오랫동안 다시 관측되지 않으면 오래된 추정을 해제하도록 하여, 잘못된 좌표를 계속 따라가는 문제를 줄였습니다.

## 2:45~3:45 — 자기 위치 추정과 지도 보정

지도에 장애물을 표시하려면 로봇 자신의 위치도 알아야 합니다.

기본적으로는 바퀴 인코더를 통해 이동 거리를 계산하고, 컴퍼스를 통해 방향을 추정합니다. 시작 위치를 기준으로 이동량을 계속 누적하는 방식입니다.

하지만 실제 테스트에서는 장애물에 걸린 상태에서도 바퀴가 회전하면서, 계산된 이동 거리와 실제 이동 거리가 달라지는 문제가 확인됐습니다. 이런 오차가 쌓이면 지도상의 로봇 위치가 틀어지고, 탐색 경로나 시작점 복귀에도 영향을 줍니다.

이를 보완하기 위해 현재 LiDAR 관측과 기존 지도의 장애물 위치를 비교하는 국소 지도 정합 기능을 추가했습니다. 현재 위치 주변에서 관측이 더 잘 맞는 위치를 찾고, 충분한 일치가 확인될 때만 위치를 보정합니다.

반대로 관측이 부족하거나 지도와 잘 맞지 않으면 억지로 보정하지 않습니다. 움직이는 사람이나 처음 발견한 장애물 때문에 위치가 잘못 이동하는 것을 줄이기 위한 조건입니다.

다만 현재 구현은 국소적인 위치 보정이며, 과거 장소를 다시 인식해 지도 전체를 수정하는 전역 루프 폐합까지 구현한 상태는 아닙니다.

## 3:45~4:50 — 탐색과 불필요한 회전 개선

이동할 곳을 정할 때는 이미 확인한 빈 공간과 아직 모르는 공간의 경계를 탐색 목표로 사용합니다. 이렇게 하면 로봇이 새 정보를 얻을 수 있는 방향으로 이동할 수 있습니다.

목표 위치까지의 경로는 A* 알고리즘으로 계산하고, 주행 중에는 LiDAR 기반 장애물 회피가 이동 명령을 보정합니다. 지도에 반영되지 않은 장애물이 나타나더라도 현재 센서 관측에 대응하기 위한 구조입니다.

실행 과정에서는 같은 구역을 맴돌거나 좌우로 불필요하게 회전하는 현상도 발견했습니다.

이를 개선하기 위해 일정 시간 동안 탐색 목표에 가까워지지 못하고 새로운 지도 정보도 얻지 못하면, 해당 목표를 일시적으로 제외하고 다른 목표를 선택하도록 했습니다.

또한 카메라로 주변을 확인하는 회전 동작이 같은 자리에서 반복되지 않도록, 직전 스캔 이후의 이동 거리와 시간 간격을 함께 확인하도록 수정했습니다.

경로를 따라갈 때 발생하는 아주 작은 방향 오차에도 매번 좌우 조향이 바뀌지 않도록 작은 오차는 무시하는 구간도 추가했습니다. 필요한 장애물 회피는 유지하면서, 의미 없는 방향 보정과 반복 스캔을 줄이려는 목적입니다.

## 4:50~5:45 — 임무 상태와 시작 지점 복귀

전체 동작은 상태 머신으로 관리합니다.

주변 확인, 탐색, 목표물 접근, 시작점 복귀, 갇힘 복구, 완료처럼 현재 임무를 상태로 나누고, 센서 관측과 진행 상황에 따라 상태를 전환합니다.

목표물을 모두 방문하면 복귀 상태로 전환하고, 시작 위치까지 경로를 다시 계산합니다. 지도 기반 경로를 구하기 어려운 경우에는 이동하면서 기록해 둔 경유점을 이용하는 복귀 방식도 사용합니다.

이 부분에서는 두 번째 목표물 방문 이후 실제로 복귀 상태로 전환되는지, 복귀 중 장애물 때문에 복구 동작을 수행하더라도 목적지가 시작점으로 유지되는지 확인했습니다.

또한 시작점에 도착해 완료 상태가 되면 이전 이동 명령이 남지 않도록, 전진 속도와 회전 속도를 즉시 0으로 만들었습니다.

성공 판정도 단순히 시작점에 도착했는지만 보지 않고, 필요한 목표물을 모두 방문했는지 함께 확인하도록 했습니다.

## 5:45~6:25 — 실행 성능과 시각화

성능 개선에서는 먼저 어느 작업이 오래 걸리는지 측정했습니다.

GPU를 사용하더라도 전체 프로그램이 자동으로 빨라지는 것은 아닙니다. 영상 전처리, 지도 처리, 화면 저장과 같은 작업이 제어 루프를 지연시킬 수 있기 때문입니다.

측정 결과를 바탕으로 색상 변환을 OpenCV로 처리하고, 지도 이미지 저장 주기를 제한했습니다. YOLO 결과도 같은 프레임에서는 공유하도록 했습니다.

실시간 화면에는 지도와 카메라 영상뿐 아니라 현재 임무 상태, 방문한 목표물 수, 추정 위치, 추론 장치와 실행 성능을 표시했습니다. 로봇이 멈추거나 돌아가는 상황에서도 어떤 상태에서 그런 행동을 하는지 확인할 수 있도록 구성했습니다.

## 6:25~7:00 — 검증 결과와 남은 과제

마지막으로 검증입니다.

이번 수정과 관련해 목표물 오인식, 오래된 목표 추정 해제, 탐색 정체, 위치 보정, 반복 회전, 시작점 복귀와 정지 동작을 다루는 회귀 테스트 28개가 통과했습니다.

다만 코드 테스트 통과와 실제 아파트 환경에서의 임무 완주는 구분해야 합니다. 실제 Webots 환경에서 목표물 두 개를 정확히 방문하고 시작점까지 복귀하는 전체 과정은 추가 검증 중입니다.

현재 지도 작성은 탐색과 목표물 방문을 지원하는 방식이며, 모든 방의 지도를 완성해야 임무가 끝나는 구조는 아닙니다.

앞으로는 실제 주행에서 위치 오차와 반복 이동이 얼마나 줄었는지 확인하고, 전체 임무의 성공률을 높이는 데 집중하겠습니다. 감사합니다.
