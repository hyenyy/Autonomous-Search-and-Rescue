# 실시간 지도 실행과 갱신 확인

## 일반 실행

프로젝트 루트에서 실행합니다.

```powershell
.venv\Scripts\python.exe -m http.server 8765 --bind 127.0.0.1
```

이미 서버가 실행 중이면 새 서버를 띄우지 않습니다. Webots에서 `worlds/apartment_sar.wbt`를 열고 실행한 다음 다음 주소를 봅니다.

- 일반 실행: http://127.0.0.1:8765/live_view.html
- 독립 검증 실행: http://127.0.0.1:8765/live_view.html?run=validation

일반 실행은 `out/`, 검증 실행은 `out/validation/`의 상태·지도·카메라를 읽습니다. 페이지의 **표시할 실행**에서 선택할 수 있습니다. 검증 실행은 검증 종료 조건에 도달하면 종료되므로 그 화면의 데이터도 더 이상 바뀌지 않습니다.

## 이번 갱신 중단의 원인과 수정

2026-09-30 확인 당시 브라우저는 종료된 검증 실행(`?run=validation`, 시뮬레이션 약 1500초)을 보고 있었습니다. 일반 실행의 `out/live_status.json`은 계속 갱신되고 있었습니다. 브라우저를 일반 실행으로 전환하여 갱신을 복구했습니다.

페이지에는 실행 종류, 마지막 데이터 시각, 갱신 중단 안내와 일반 실행 링크를 추가했습니다. 상태 요청이 4초 동안 응답하지 않으면 취소하고 다음 주기에 재시도하므로 요청 하나 때문에 갱신이 무기한 멈추지 않습니다. 현재 실행의 실제 위치 추정 방식도 상태 데이터에서 표시합니다.

## 동작 확인

1. 상단에 `일반 실행 · 실시간 연결`이 표시되는지 확인합니다.
2. 시뮬레이션 시간이 증가하고 카메라와 지도 이미지가 바뀌는지 확인합니다.
3. Webots를 일시정지하면 약 5초 후 갱신 중단 안내가 표시됩니다. 실행을 재개하면 자동으로 연결 표시가 돌아옵니다.
4. 연결 대기가 계속되면 HTTP 서버, 선택한 실행, Webots 컨트롤러 오류를 확인합니다. 브라우저 새로고침만으로 종료된 컨트롤러가 다시 실행되지는 않습니다.

코드를 수정한 뒤에는 Webots 시뮬레이션을 재시작해야 실행 중인 Python 컨트롤러에도 변경 사항이 적용됩니다. 페이지 새로고침은 HTML 변경만 적용합니다.
